# 🌱 Smart Garden IoT - v2.0 Update

**"The Intelligent Upgrade"**

We are excited to introduce **Smart Garden v2.0**! This release brings a completely overhauled user experience, robust firmware updates, and comprehensive history tracking.

---

## 🚀 New Features

### 📱 App Enhancements
*   **🔄 In-App Updates**: No more manual installs! The app now checks GitHub for the latest version and updates itself with a single tap.
*   **📊 History & Insights**: View detailed Soil Moisture trends over the last 12 hours.
*   **🎨 Hybrid UI**: A stunning new interface with glassmorphism, animated status indicators, and a responsive design.
*   **⚡ Optimized Performance**: Faster connection times with Firebase caching and reliable background service.

### 🧠 Firmware (ESP8266)
*   **🔒 Pump Safety Lock**: Automatic cut-off after 15 seconds to prevent over-watering or pump burnout.
*   **📡 Improved Connectivity**: Better reconnection logic for WiFi and MQTT/Firebase.

## 📦 Installation Instructions

1.  **Download**: Click the `EcoSync.apk` link below (Assets section).
2.  **Install**: Open the file on your Android device.
    *   *Note: You may need to "Allow Install from Unknown Sources".*
3.  **Enjoy**: Log in and start monitoring your plant!

### 🔧 For Developers
*   **Firmware**: The `Main.ino.generic.bin` file is provided for OTA updates via Arduino.
*   **Source**: Check the `feature/hybrid-ui` branch for the latest code.
